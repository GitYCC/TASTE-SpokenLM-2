# CosyVoice 架構概述

## 系統架構

CosyVoice 是一個基於大語言模型的可擴展多語言零樣本文字轉語音合成系統。系統採用三階段架構設計：

```
文字輸入 → LLM (語意建模) → Flow (聲學建模) → HiFi-GAN (語音生成) → 語音輸出
     ↓           ↓              ↓                ↓
前端處理 → 語音語意 Token → 梅爾頻譜特徵 → 高品質語音波形
```

### 整體數據流程
1. **文字預處理**: 輸入文字經過前端處理模組進行規範化和分詞
2. **語意建模**: LLM 將文字轉換為語音語意 token 序列
3. **聲學建模**: Flow 模型將語意 token 轉換為梅爾頻譜特徵
4. **語音生成**: HiFi-GAN 將梅爾頻譜轉換為高品質語音波形

## 核心組件

### 1. 大語言模型 (LLM)

**架構特點**:
- 基於 Transformer 的語言模型架構
- 使用 Qwen2ForCausalLM 作為基礎模型
- 支援多語言文字理解和語音語意建模

**主要功能**:
- **文字編碼**: 將輸入文字轉換為語意表示
- **語意生成**: 生成語音對應的語意 token 序列
- **多語言處理**: 支援中英日韓等多語言處理
- **指令理解**: 支援自然語言指令控制語音特性

**模組組成**:
- `text_encoder`: 文字編碼器 (ConformerEncoder)
- `llm`: 大語言模型核心 (TransformerEncoder)
- `sampling`: 採樣策略 (RAS - Repetition Aware Sampling)

### 2. 流匹配模型 (Flow Matching)

**架構特點**:
- 使用 MaskedDiffWithXvec 架構
- 結合擴散模型和流匹配技術
- 支援說話人嵌入向量條件生成

**主要功能**:
- **聲學建模**: 將語意 token 轉換為梅爾頻譜特徵
- **時序對齊**: 透過長度調節器控制語音時序
- **音色控制**: 透過說話人嵌入實現音色控制
- **品質優化**: 使用條件流匹配提升音質

**模組組成**:
- `encoder`: ConformerEncoder 編碼器
- `length_regulator`: 長度調節器 (InterpolateRegulator)
- `decoder`: 條件流匹配解碼器 (ConditionalCFM)

### 3. 語音生成器 (HiFi-GAN)

**架構特點**:
- HiFTGenerator 生成器架構
- 多尺度判別器設計
- 基於神經聲碼器的高品質語音合成

**主要功能**:
- **波形生成**: 將梅爾頻譜轉換為語音波形
- **音質提升**: 透過對抗訓練提升語音自然度
- **F0 預測**: 集成 F0 預測器控制音調
- **多尺度優化**: 支援多個時頻解析度的優化

**關鍵特性**:
- 支援即時推理
- 低延遲語音生成
- 高保真度音質輸出

### 4. 前端處理 (Frontend)

**架構特點**:
- CosyVoiceFrontEnd 統一前端介面
- 支援多語言文字規範化
- 整合多種特徵提取器

**主要功能**:
- **文字規範化**: 數字、符號、縮寫等標準化處理
- **分詞處理**: 多語言分詞和 token 化
- **特徵提取**: 音頻特徵和說話人特徵提取
- **語音處理**: 語音預處理和品質檢查

**支援工具**:
- `ttsfrd`: 高性能文字規範化 (可選)
- `wetext`: 備用文字規範化工具
- `whisper`: 多語言分詞器
- ONNX 模型推理支援

### 5. 分詞器 (Tokenizer)

**架構特點**:
- 基於 Whisper 的多語言分詞器
- 支援特殊標記和控制符號
- 可配置的詞彙表大小

**主要功能**:
- **多語言分詞**: 支援 100+ 語言的分詞
- **特殊標記**: 支援語言標記、情感標記等
- **控制符號**: 支援笑聲、停頓等韻律控制
- **詞彙管理**: 靈活的詞彙表配置

## 數據流程

### 訓練階段數據流程

1. **數據預處理**:
   ```
   原始數據 → Parquet格式 → 文字標準化 → 音頻重採樣 → 特徵提取
   ```

2. **特徵計算**:
   ```
   音頻 → 梅爾頻譜 → F0特徵 → 說話人嵌入 → 語音Token化
   ```

3. **模型訓練**:
   ```
   批次數據 → LLM訓練 → Flow訓練 → HiFi-GAN訓練 → 模型優化
   ```

### 推理階段數據流程

1. **SFT 推理流程**:
   ```
   輸入文字 → 文字規範化 → 前端處理 → LLM推理 → Flow推理 → HiFi-GAN → 語音輸出
   ```

2. **零樣本推理流程**:
   ```
   輸入文字 + 參考語音 → 說話人特徵提取 → 條件化LLM → Flow → HiFi-GAN → 語音輸出
   ```

3. **跨語言推理流程**:
   ```
   目標語言文字 + 源語言語音 → 跨語言特徵對齊 → 條件化生成 → 語音輸出
   ```

4. **串流推理流程**:
   ```
   文字塊 → 增量處理 → 分段生成 → 串流輸出 → 實時播放
   ```

## 模型類型

### CosyVoice 1.0 vs 2.0 vs 3.0

| 特性 | CosyVoice 1.0 | CosyVoice 2.0 | CosyVoice 3.0 |
|------|---------------|---------------|---------------|
| **核心架構** | LLM + Flow + HiFi-GAN | 優化的LLM + 改進Flow + 增強HiFi-GAN | 擴展架構 + 後訓練優化 |
| **參數規模** | 300M | 500M | 更大規模 |
| **語言支援** | 中英日韓粵 | 增強多語言 + 方言 | 野外語音支援 |
| **推理速度** | 標準速度 | 2倍提升 | 進一步優化 |
| **串流支援** | 基礎串流 | 雙向串流 | 增強串流 |
| **首包延遲** | ~300ms | ~150ms | 更低延遲 |
| **音質提升** | MOS 5.4 | MOS 5.53 | 進一步提升 |
| **穩定性** | 基準水平 | 30-50%錯誤率降低 | 野外場景適應 |
| **特殊功能** | - | 情感控制、方言支援 | 後訓練技術 |

### 架構演進

**CosyVoice 1.0**:
- 基礎的 LLM + Flow + HiFi-GAN 架構
- 支援基本的多語言 TTS
- 50Hz 幀率處理

**CosyVoice 2.0**:
- 優化的模型架構和訓練策略
- 增強的多語言和方言支援
- 改進的串流推理能力
- 25Hz 高效幀率處理
- 集成 vLLM 支援加速推理

**CosyVoice 3.0**:
- 野外語音生成能力
- 擴展和後訓練技術
- 更強的泛化能力

## 設計理念

### 核心設計原則

**1. 可擴展性 (Scalability)**
- 模組化架構設計，各組件可獨立優化
- 支援不同規模的模型部署
- 靈活的配置系統支援多種場景

**2. 多語言原生支援**
- 從架構層面考慮多語言特性
- 統一的多語言處理框架
- 跨語言知識遷移能力

**3. 零樣本泛化能力**
- 基於語意建模的零樣本學習
- 強大的說話人特徵提取和建模
- 跨領域適應能力

**4. 實時性優化**
- 串流處理架構設計
- 低延遲推理優化
- 記憶體和計算資源高效利用

**5. 品質與效率平衡**
- 多階段優化策略
- 品質導向的損失函數設計
- 推理效率和音質的最佳平衡

### 技術創新點

**1. LLM 驅動的語音合成**
- 將大語言模型引入 TTS 領域
- 語言理解和語音生成的統一建模
- 支援複雜的語言現象處理

**2. 流匹配技術**
- 結合擴散模型和流匹配的優勢
- 更穩定的訓練過程
- 高品質的聲學特徵生成

**3. 統一的多模態前端**
- 文字、語音、說話人特徵的統一處理
- 靈活的條件控制機制
- 多種推理模式的無縫切換

**4. 重複感知採樣 (RAS)**
- 解決 LLM 推理中的重複問題
- 提升生成穩定性
- 更自然的語音韻律

### 架構優勢

- **模組化**: 每個組件職責清晰，便於維護和升級
- **可配置**: 豐富的配置選項支援不同需求
- **可擴展**: 支援新語言、新功能的快速集成
- **高效能**: 優化的推理引擎和記憶體管理
- **開放性**: 開源友好的架構設計
